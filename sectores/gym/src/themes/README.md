# Temas del kit gym

- `brava.css`: concepto Brava Club (gym de chicas).
- `neutro.css`: valores de partida heredados de la base (se sustituirá por el tema gym mixto).

Para activar un tema: cambia el `import` del tema en `src/layouts/BaseLayout.astro`.
Todo tema debe definir las mismas variables (ver `base/DESIGN.md`).
