# Kit gym

Componentes y temas pensados para gimnasios y estudios de entrenamiento.
Nació copiando `base/` (SEO, datos del negocio, accesibilidad, legales) el 20 nov 2026.

## Estado
- **En construcción.** Ahora contiene los componentes genéricos de partida de la base; se rediseñarán
  para gimnasio con el concepto **Brava Club** (tema `src/themes/brava.css`).

## Componentes previstos
- Hero editorial
- Clases y disciplinas
- Horario semanal de clases
- Tarifas y bonos
- Entrenadoras / equipo
- Galería
- Opiniones
- Reserva de clase de prueba por WhatsApp
- Cabecera y pie con la identidad de cada marca

## Temas
- `brava.css`: Brava Club (gym de chicas, rojo, crema y negro). Ver `claude/concepto-gym-girls.md`.
- Gym mixto (próximamente): mismas piezas con otro tema, para demostrar que el kit sirve a marcas distintas.
